# Copilot / VSCode manual bridge template

Template only; no installed extension, automatic instructions merge or headless Chat API. Use `<PACK>/docs/work-queue.md` and the terminal task template for queue operations.

Optional chat assistance receives the supplied canonical contract and one bounded job in a fresh context with no tools. Return only a proposal; no target edits, Git/build/tests/network or agents. If the host cannot enforce this, author JSON manually. Native Copilot CLI is unavailable; do not enable all-tools permissions to force it. Only the separately authorized script integrator applies edits and verifies them serially.
